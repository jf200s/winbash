# 委派式交付（一页摘要）

适用：多步编码、并行任务、上下文密集的只读调查。简单问答直接做。

1. ≥2 个无共享状态的任务 → 同一条消息里并发派发；一次派发只做一件内聚的事。
2. 提示词里喂目标、文件范围、验收命令、汇报格式；歧义在派发前消掉，禁止“顺便”。
3. 写代码的子代理必须有自己的 worktree + 分支；只读免隔离。
4. 子代理必须回四件：分支+commit、验证命令与退出码、改动文件+漏改清单、存疑点。
5. 主代理亲手看 diff、跑全量门禁且连跑 ≥2 次；跨进程/协议/生命周期加端到端“先 A 后 B”序列。
6. 写并发 2–3、只读 4–6 是上限；并发共用端口/状态必须隔离。
7. 不静默、文档同步、临时文件不进库；区分“已验证”与“推断”。

细节：调用 skill `delegated-delivery`。
